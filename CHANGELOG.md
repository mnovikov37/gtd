### Сборщик проекта [AI]
- Списки файлов для сборки `__build.lst` сделаны опциональными (были обязательными). Теперь, если сборщик не найдёт список в директории, он будет обходить её рекурсивно и включать в сборку код из всех найденных файлов. Если внутри поддиректории встретится `__build.lst`, то сборщик будет действовать в соответствии с его содержимым
- Добавлена возможность поставить игнор для сборщика на любой файл. Для этого в первой строке кода нужно указать аннотацию `@build-ignore`. К аннотации после пробела можно добавить комментарий. Встретив такую анотацию, сборщик не будет включать код из файла в сборку и выведет в лог сообщение: `ignored: $file_path: $comment_text`
